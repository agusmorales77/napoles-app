# Agenda Napoles Barbería

Agenda semanal de turnos para Napoles Barbería (Almirante Brown 274, Carlos Casares) que arma sola la historia de Instagram (1080 × 1920) con los horarios libres o la lista de precios.

- Elegí hasta 7 días, cargá hasta 6 horarios por día y agendá clientes (nombre, servicio, teléfono, nota).
- Los turnos ocupados se ocultan (o se muestran tachados) en la historia.
- Cuatro modelos de historia con la estética del local (negro, paneles 3D y luces LED en hexágono): Neón, Últimos, Claro y Foto (con una foto del local).
- Precios, agenda con pagos y asistencia, y balance mensual.
- "Ver para captura" muestra la historia a pantalla completa; "Descargar imagen" baja el PNG.

Es un solo archivo estático (`index.html`). Los datos se guardan en el navegador de cada dispositivo.
